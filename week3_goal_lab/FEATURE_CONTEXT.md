# Feature Context - StudyGoal

## 내가 작성할 내용

### 사용자 목표
학생이 오늘 공부할 목표와 완료 여부를 한 화면에서 확인한다.

### 사용자 스토리
앱프로그래밍을 배우는 학생으로서 나는 오늘의 학습 목표를 등록하고 완료 표시하고 싶다. 그래서 남은 학습 항목을 바로 확인할 수 있다.

### 범위

#### 이번 실습에서 만든다
- [x] 1~20자의 학습 목표를 추가한다.
- [x] 공백 입력을 차단하고 오류 문구를 표시한다.
- [x] 목표를 완료 또는 미완료로 전환한다.

#### 이번 실습에서 만들지 않는다
- [x] 로그인과 여러 사용자
- [x] 서버 또는 데이터베이스 저장
- [x] 알림과 일정 연동
- [x] 앱 재시작 후 상태 복원

### AC1 정상 입력
- Given: 목표 목록이 비어 있고 `Dart 객체지향`이 입력되어 있다.
- When: `추가` 버튼을 누르면
- Then: 목록에 미완료 상태의 `Dart 객체지향` 항목이 표시된다.
- Evidence: `evidence/ac1-valid.png`

### AC2 공백 입력
- Given: 목표 입력란에 공백만 입력되어 있다.
- When: `추가` 버튼을 누르면
- Then: 목록은 변경되지 않고 `목표를 입력하세요` 오류 문구가 표시된다.
- Evidence: `evidence/ac2-empty.png`

### AC3 완료 전환
- Given: `Dart 객체지향` 목표가 미완료 상태로 목록에 있다.
- When: 해당 목표의 체크박스를 선택하면
- Then: 체크 상태와 함께 상태 문구가 `완료`로 변경된다.
- Evidence: `evidence/ac3-complete.png`
